# Habit Tracker — Simple Version

A Python console program for tracking habits.

## What does the program do?

- adds habits,
- deletes habits,
- marks the completion of a habit for a given day,
- shows a list of habits,
- shows statistics,
- imports sample habits from the `HabitData.txt` file,
- saves data to the `habits.json` file.

## How to run?

1. Place the `habit_tracker_simple.py` and `HabitData.txt` files in one folder.
2. Open a terminal in that folder.
3. Run:

```bash
python habit_tracker_simple.py
```

## Files created by the program

- `habits.json` — program data,
- `log.txt` — log of actions performed.
